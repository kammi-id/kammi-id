# 03 — Sidebar Struktur Anak

**What to build:** Detail Struktur yang memiliki Struktur Anak menyediakan sidebar kanan untuk menavigasi anak langsung, dengan pencarian dan pagination. Sidebar tetap berguna di layar kecil dan tidak tampil untuk leaf.

**Blocked by:** 01 — Detail Struktur dan integritas jalur.

**Status:** ready-for-agent

- [ ] Sidebar hanya memuat Struktur Anak langsung yang terlihat; Struktur Terhapus tidak muncul.
- [ ] Pencarian, pagination, empty state, dan URL state bekerja tanpa mengubah Struktur detail yang sedang dibuka.
- [ ] PW menampilkan “Jumlah PD”; PD dan PDLN menampilkan “Jumlah Komisariat”; PK tidak menampilkan metrik Struktur Anak atau sidebar kosong.
- [ ] Pada layar kecil sidebar mengikuti konten utama, dan tautan navigasinya tetap dapat dioperasikan dengan keyboard.
