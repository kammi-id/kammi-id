# Event Terbit tetap menjadi arsip

Event adalah Artikel pengumuman milik sebuah Struktur, terpisah dari catatan
Daurah dan pengelolaan Peserta. Menjadi lewat waktu atau dibatalkan tidak
mencabut pengumumannya: Event yang dibatalkan tetap menjelaskan pembatalannya,
dan Event yang diarsipkan keluar dari daftar tanpa mematikan Permalink-nya.

Kami memperluas prinsip arsip pada ADR 0013 ke Event yang sudah Terbit:
Permalink-nya tetap terbuka ketika Struktur menjadi Non-Aktif, sementara
beranda dan daftar Event berhenti melayani. Mematikan tautan pengumuman ketika
kepengurusan berhenti lebih sederhana, tetapi menghilangkan informasi yang
sudah dibagikan, termasuk pembatalan kegiatan. Event tetap milik Situs
Strukturnya sendiri; keputusan ini tidak menambahkan agregasi nasional Event.
