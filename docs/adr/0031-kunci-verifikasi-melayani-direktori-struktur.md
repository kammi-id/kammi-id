# Kunci Verifikasi melayani Direktori Struktur

Kunci Verifikasi yang dibuat Root juga mengautentikasi Direktori Struktur REST
v1, selain Verifikasi Kader. Struktur bukan data Kader, tetapi direktori tetap
berada di balik kunci bersama agar pemakaian tercatat dan dibatasi tanpa
memperkenalkan identitas pemegang atau Cakupan baru.
